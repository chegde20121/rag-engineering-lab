# JES2 Operations Guide

## Spool management
JES2 manages spool space for job input and output. Use `$D SPOOL` to display spool utilization.

| Command | Purpose | Example |
| --- | --- | --- |
| `$D SPOOL` | Display spool utilization | `$D SPOOL` |
| `$D JOB` | Display job information | `$D JOB` |

## Troubleshooting
The message `IEF450I JOB1234 - ABEND=S0C4` identifies an abnormal termination. Do not strip punctuation from diagnostic identifiers.
